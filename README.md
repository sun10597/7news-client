# 7News
**카테고리 기반 뉴스 웹 서비스**

React와 Vite를 활용해  
실시간 뉴스 데이터를 조회할 수 있는 SPA 기반 프론트엔드 프로젝트입니다.

---

## 📌 프로젝트 개요

- **기간**: 2025.05.21 ~ 2025.06.25  
- **역할**: UI/UX 설계 · 뉴스 데이터 연동 · 페이지 구조 설계 · 배포  
- **유형**: 2인 프로젝트 (프론트엔드 웹 서비스)

---

## 🛠 기술 스택

- **Frontend**: React, Vite, JavaScript
- **Styling**: Tailwind CSS
- **Data**: Axios (뉴스 API 연동)
- **Deploy**: Vercel

---

## ✨ 주요 기능

- 카테고리 기반 뉴스 분류 (정치 · 경제 · 사회 · 문화 등)
- 뉴스 검색 기능 (키워드 필터링)
- HOT 뉴스 / 최신 뉴스 분리 제공
- 반응형 UI (PC · Tablet · Mobile)
- SPA 구조 기반 빠른 페이지 전환

---

## 🧩 담당 업무

- React Router 기반 SPA 구성
- Tailwind CSS를 활용한 반응형 UI 구현
- Axios를 통한 뉴스 API 연동 및 데이터 처리
- 프로젝트 구조 설계 및 Vercel 배포

---

## 🏆 성과 및 배운 점

- 실제 서비스 형태의 프론트엔드 프로젝트 기획·구현·배포 경험
- SPA / CSR 렌더링 구조 이해도 향상
- 외부 API 연동 및 UI/UX 구성 역량 강화
